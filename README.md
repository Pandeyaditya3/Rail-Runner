# Rail Runner

A Subway Surfers-style endless runner built with vanilla JavaScript and HTML5 Canvas. No libraries, no build step: just one HTML file.

## Features
- Pseudo-3D three-lane track
- Trains, jump barriers, and overhead bars to dodge
- Coins to collect
- Speed that increases over time
- Best score saved in the browser
- Touch swipe and keyboard controls

## How to Play
Open `runner.html` in any modern browser.

| Action | Touch | Keyboard |
|---|---|---|
| Move left/right | Swipe left/right | ← → or A / D |
| Jump | Swipe up | ↑, W, or Space |
| Roll | Swipe down | ↓ or S |
| Start/restart | Tap | Space or Enter |
